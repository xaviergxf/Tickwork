# Tickwork.EntityFrameworkCore

Entity Framework Core integration for [Tickwork](https://github.com/arcenox/Tickwork), a high-performance background job scheduler for .NET.

This package enables persistence of time-based and cron-based jobs using EF Core, allowing for robust tracking, retry logic, and job state management.

---

## 📦 Installation

```bash
dotnet add package Tickwork.EntityFrameworkCore
